# sienna 的地球online

[打开个人作品站](https://sienna-cat.github.io/sienna-earth-online/) · [专业作品集](https://sienna-cat.github.io/drivefollow/portfolio/)

以可探索的小岛呈现工作项目、个人开发作品与评测方法，支持直接打开交互演示。

## 内容
- 工作项目：外呼线索分流、知识问答、核单履约、跨行业交付和车主运营。
- 灵感工坊：DriveFollow、DrivePulse、DriveReach、LoopLab，以及方向探索、地址工具与黑客松作品。
- 评测研究：意向规则对照、人群与地址策略比较、Bad Case 和产品迭代方法。
- 创作分享：个人内容与探索记录。

## 使用
可以拖动环顾、点击营地，或使用“直接试玩作品”。支持手机访问，演示操作使用示例数据并保存在当前浏览器。

## 技术
Three.js 场景、原生 JavaScript 交互与 Vite 静态构建，部署在 GitHub Pages。项目导航与演示使用相对路径。

本仓库保存发布文件。个人开发项目的源码入口见站内各作品。
