# 四个作品，一条业务主线

围绕汽车营销与服务，将任务拆为人群准备、购车跟进、卖车协同和策略复核。每个作品都聚焦明确角色与操作目标。

| 作品 | 面向角色 | 核心流程 |
| --- | --- | --- |
| DriveFollow | 销售顾问 | 客户原话 → 条件与许可 → 核实 → 确认与执行 |
| DrivePulse | 车主运营 | 人群筛选 → 触达资格 → 人工审批 → 反馈回流 |
| DriveReach | 外呼与人工坐席 | 卖车意向 → 转接或回拨 → 时间确认 → 拒联取消 |
| LoopLab | 策略运营与复核人员 | 策略冻结与比较；地址证据、分流与人工裁决 |

## 推荐体验顺序
1. [DriveFollow](https://sienna-cat.github.io/drivefollow/inquiry.html)：完成一次询价处理，再尝试撤回许可。
2. [DrivePulse](https://sienna-cat.github.io/drivepulse/)：选择人群、审批任务，检查执行前资格变化。
3. [DriveReach](https://sienna-cat.github.io/drivereach/)：确认回拨时间，观察转接、待办和取消状态。
4. [LoopLab](https://sienna-cat.github.io/looplab/)：冻结客群策略，或切换地址规则比较错误放行与人工复核。

## 共同的产品方法
输入来源可查，判断与动作分开，异常有处理出口，结果进入复盘。各作品通过独立任务展示这些方法，便于直接操作与检查。
