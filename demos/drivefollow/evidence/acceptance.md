# 场景验收与质量控制

从客户原话到任务执行，将产品要求转化为可重复的检查情形。

| 场景 | 预期行为 |
| --- | --- |
| 有点贵、不急、问落地价 | 保留价格咨询与顾虑，购买时间独立记录 |
| 我可没说不买 | 结合否定范围判断，不按“不买”关键词直接拒绝 |
| 那分三年呢 | 结合前文保留分期咨询，补齐付款条件 |
| 不要电话，报价发已有企微 | 电话拒绝，企微只允许本次报价 |
| 报价资料过期或条件冲突 | 停止执行，转核实或补问 |
| 客户自述已加企微 | 独立检查关系后再进入任务 |
| 建单后撤回联系许可 | 取消相关待执行任务并记录原因 |
| 连续点击确认 | 复用同一待办，避免重复建单 |
| 建单后更改付款条件 | 重新核实并确认任务依据 |
| 刷新、导出、重置 | 状态可恢复，记录可导出，案例可重新体验 |

## 分层验收
- 理解质量：意向、知识状态、联系许可与动作是否一致。
- 任务质量：资格检查、重复保护、回执、失败恢复和撤回处理。
- 业务指标：有效承接、建议采用与修改、复核和返工耗时。
